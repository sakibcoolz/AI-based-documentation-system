# Tools and MCP

## Graphify
Use Graphify to build repository graph context before architecture-level conclusions.

## Context7 MCP
Use Context7 for current external framework and library documentation only.

## Linear MCP
If configured, use Linear for phase/task planning, dependencies, workflow state, and implementation evidence links.

## OpenRouter
Use OpenRouter as the model gateway via aliases instead of hardcoded provider IDs.

## Tooling Rules
- Repository evidence beats external tool output when they conflict.
- MCP-derived task status is not proof of repository behavior.
- Tool failures must be observable and retryable where safe.

# Development Workflow

1. Read `PRT.md`, `docs/`, and `.github/copilot-instructions.md`.
2. Refresh Graphify context if available.
3. Use Context7 for planned framework guidance.
4. Update architecture/task documentation first.
5. Wait for implementation approval.
6. During implementation, update impacted docs with every change.
7. Do not mark work done without acceptance evidence.

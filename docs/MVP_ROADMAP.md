# MVP Roadmap

## Phase 00 — Foundation
Establish the repository contracts, documentation standards, and quality gates.

## Phase 01 — Static Repository Intelligence
Safely ingest repositories, detect stacks, extract symbols, and persist evidence-backed structural knowledge.

## Phase 02 — AI Intelligence
Add model routing, ADK orchestration, specialist agents, and external tool adapters.

## Phase 03 — Documentation
Generate documentation, diagrams, and review artifacts with evidence traces.

## Phase 04 — UI
Deliver the dashboard, architecture explorer, Q&A, and evidence views.

## Phase 05 — Hardening
Add incremental analysis, observability, security hardening, and final MVP acceptance.

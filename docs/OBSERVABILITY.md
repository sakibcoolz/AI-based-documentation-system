# Observability

## Goals
- Trace scan, enrichment, and generation workflows end to end.
- Measure latency, retry counts, queue depth, and artifact success/failure.
- Track model usage, token cost, and failure rates by alias.

## Signals
- Traces: repository intake, scan steps, Graphify, Context7, agent orchestration.
- Metrics: scan duration, parse coverage, finding counts, document generation rates.
- Logs: structured event logs with scan IDs, repository IDs, and correlation IDs.
